Morse Code Decoder

A Morse code decoder built in Verilog on a PYNQ-Z2 FPGA board. It uses a synchronizer and a four-state state machine to read button presses reliably despite timing jitter. When the state machine misbehaved during testing, I found the problem by routing its states to the board's LEDs and fixed it with pulse conditioning. (In progress)
